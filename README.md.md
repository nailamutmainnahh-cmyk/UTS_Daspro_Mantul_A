# Proyek Pemesanan Makanan

## 1. Deskripsi Proyek

**Pemesanan Makanan** adalah program sederhana berbasis bahasa Pascal
yang dibuat untuk membantu proses pemesanan makanan. Program ini
menampilkan pilihan makanan, menerima pilihan dan jumlah pesanan dari
pengguna, menghitung biaya pesanan, serta menampilkan total pembayaran.

Proyek ini dibuat sebagai bagian dari tugas Ujian Tengah Semester (UTS)
mata kuliah Dasar Pemrograman.

## 2. Tujuan Proyek

-   Menerapkan dasar-dasar pemrograman menggunakan bahasa Pascal.
-   Menggunakan input dan output untuk berinteraksi dengan pengguna.
-   Menerapkan percabangan untuk menentukan pilihan menu dan harga.
-   Melakukan perhitungan total biaya berdasarkan jumlah pesanan.
-   Melatih kerja sama kelompok dan dokumentasi proyek melalui GitHub.

## 4. Fitur Utama Program

1.  **Menampilkan daftar makanan**\
    Program menampilkan pilihan makanan beserta harga masing-masing.
2.  **Memilih makanan**\
    Pengguna memasukkan pilihan menu yang ingin dipesan.
3.  **Memasukkan jumlah pesanan**\
    Pengguna menentukan jumlah makanan yang dipesan.
4.  **Menghitung total pembayaran**\
    Program menghitung harga makanan dikalikan jumlah pesanan.
5.  **Menampilkan hasil pesanan**\
    Program menampilkan ringkasan pesanan dan total biaya yang harus
    dibayar.

## 5. Logika Program

Alur kerja program secara umum adalah sebagai berikut:

1.  Program dimulai.
2.  Program menampilkan daftar menu makanan dan harga.
3.  Pengguna memilih makanan.
4.  Pengguna memasukkan jumlah makanan yang dipesan.
5.  Program menentukan harga sesuai pilihan menu.
6.  Program menghitung total biaya pesanan.
7.  Program menampilkan detail pesanan dan total pembayaran.
8.  Program selesai.
